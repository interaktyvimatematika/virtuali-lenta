P7.7.2 ONLINE-P1 — BENDROS LENTOS KANDIDATĖ

Tikslas
- Palikti P7.7.2 matematikos ir pratybų branduolį kuo mažiau pakeistą.
- Pridėti bendrą Firebase Realtime Database sesiją.
- Du langai su tuo pačiu ?room=KODAS mato tą pačią lentos darbo būseną.

Šiame P1 sinchronizuojama
- piešimo / trynimo brūkšniai (piešimas siunčiamas beveik gyvai);
- mišrūs teksto + formulės laukai;
- lentoje įterptos pavienės užduotys;
- lentoje įterptos puslapinės pratybos;
- pagrindinio pratybų lango padėtis ir dydis.

Kol kas sąmoningai NEsinchronizuojama
- kiekvieno žmogaus kameros mastelis ir slinktis;
- aktyvus įrankis ir pažymėjimas;
- mokinio / mokytojo režimas;
- pagrindinio vidinio P7.7.2 pratybų lango atsakymų eiga.

Kodėl
P1 skirtas patikrinti bendros lentos ryšį neperrašant stabilaus P7.7.2 branduolio. Kitas etapas bus atskirai įkeliamas pratybų dokumentas.

Svarbu
- Firebase konfigūracija perimta iš ankstesnio jūsų ištestuoto bendros lentos prototipo.
- Norint dalintis nuoroda tarp dviejų kompiuterių, šį aplanką reikia patalpinti internete (pvz., GitHub Pages).
- Paleidus lokaliai iš index.html Firebase ryšį galima testuoti, tačiau file:// nuorodos kitam kompiuteriui siųsti negalima.
- Kandidatė naudoja atskirą localStorage raktą, todėl stabili P7.7.2 lokali būsena neliečiama.
